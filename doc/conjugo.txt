*conjugo.txt*  Verb conjugations from Conjugo in a floating window

==============================================================================
CONTENTS                                                             *conjugo*

Conjugo (`conj`) conjugates French, Italian, Spanish, Portuguese, English,
German and Russian verbs. This plugin shows the conjugation of the verb under the cursor in a
floating window and highlights the form under the cursor in the table.

Requirements: Neovim 0.10+, and `conj` on your PATH
(`uv tool install git+https://github.com/guilhermegarcia/conj`).

==============================================================================
COMMAND                                                                *:Conj*

:Conj [{lang}]      Conjugate the word under the cursor. {lang} is one of
                    fr, it, es, pt, en, de, ru, and searches only that language
                    (as does |b:conj_lang|). Without it, every language is
                    searched, and the guessed language's verbs come first:
                    the spell-check language (only when |'spell'| is on and
                    |'spelllang'| names one of those languages, not a list
                    of several), else `default_lang` (see |conjugo.setup()|).
                    Inflected forms work (parlons, went, hablé).
                    French elisions (j'aime) and hyphenated clitics
                    (levantou-se) are stripped. Not a verb: a message.

When several verbs have the form (suis: être, suivre; fui: ser, ir), the
second header line lists them, best first, e.g. `1/3  ser · ir · fuir   p/n`.

In the window:
  `p` / `n`         previous / next candidate verb (wraps around)
  `q` / `<Esc>`     close (it also closes when you leave it)

                                                                *b:conj_lang*
b:conj_lang         Only this language in this buffer, e.g.
                    `let b:conj_lang = 'it'`.

Map it yourself, e.g.: >lua
    vim.keymap.set("n", "\\Lc", "<cmd>Conj<cr>")
<
==============================================================================
SETUP                                                       *conjugo.setup()*

Optional. Defaults: >lua
    require("conjugo").setup({
      cmd = { "conj" },     -- how to run Conjugo
      default_lang = nil,   -- e.g. "fr": its verbs listed first
      border = "rounded",
      simple = false,       -- true: simple tenses only
      glosses = 3,          -- glosses under the header
      gap = 3,              -- spaces between tense columns
      max_width = 0.9,      -- fraction of the editor
      max_height = 0.85,
    })
<
                                                    *conjugo.lookup()*
require("conjugo").lookup({ word = ..., lang = ... }) looks up any word.

==============================================================================
HIGHLIGHTS                                                *conjugo-highlights*

ConjugoMatch        the form(s) matching the word        (IncSearch)
ConjugoHeader       verb, language, auxiliary            (Title)
ConjugoInfo         "parlons → parler: Présent 1p"       (Special)
ConjugoSection      INDICATIF, SUBJONCTIF...             (Statement)
ConjugoTense        tense names                          (Identifier)
ConjugoCompound     compound tense names and forms       (Comment)
ConjugoPron         subject pronouns                     (Comment)
ConjugoGloss        English glosses                      (Normal)
ConjugoCandidate    the candidate-verb line              (Comment)
ConjugoCurrent      the candidate shown                  (Title)
